# Aashish Shop Website

Responsive English/Nepali website for New Ganesh Watch & Eyewear Shop.

## Features
- Mobile-friendly homepage and navigation
- English / नेपाली language switcher
- Illustrated watches, eyeglasses, sunglasses and clocks collections
- Google Maps directions

## Preview
Open `index.html` in any browser. No installation needed.

## Before publishing
Confirm the shop name, product categories, and the map coordinates (26.7119444, 86.4824444), which came from the supplied screenshot. Add verified contact details, opening hours and real shop photos. Product visuals are illustrations, not confirmed inventory.

## Publish with GitHub Pages
The repository is currently private. GitHub Pages availability for private repositories depends on your plan. For free public Pages hosting, make the repository public if appropriate, then open Settings → Pages → Deploy from a branch → main → /(root) → Save.
